# Phase Lock Assets

All visual elements, particles, animations, and sound effects in **PHASE LOCK** are 100% procedurally synthesized:

- **Graphics**: Rendered programmatically via HTML5 Canvas 2D and modern CSS Glassmorphism.
- **Audio**: Generated in real time using the browser's native Web Audio API (procedural oscillators, envelopes, and filters).
- **Typography**: Uses high-performance native system font stacks (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, monospace) with zero external network requests.
- **Offline Delivery**: Complete self-contained operation without external textures, sprites, or audio media files.
